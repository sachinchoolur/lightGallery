lightGallery facts and figures

View as Markdown Open in Claude Open in ChatGPT

One page of checkable facts: how big lightGallery is, what it depends on, what it runs in, what it plays, and what it costs. Sizes are measured from the build this site was made with.

lightGallery is an open-source JavaScript lightbox and gallery for images and video, with native React, Vue and Angular packages built on one shared core, no dependencies, and every feature outside the core shipped as an opt-in plugin. This page is the reference for the numbers; the figures that come from the build are measured when the site is built, so they match the version in the heading below.

How big is lightGallery?

The core is the lightbox itself. Thumbnails, zoom, video and the rest are plugins with their own entry points, so a gallery pays only for the features it imports. A typical image gallery with thumbnails and zoom is the core plus two plugins, about 30 KB of JavaScript gzipped.

Node 18 or later is required for the build tooling; the browser bundles have no Node requirement.

Which browsers does it run in?

Current evergreen browsers: Chrome, Edge, Firefox and Safari on desktop, Safari on iOS and Chrome on Android. The builds target ES2017 and run without transpiling or polyfills. Internet Explorer is not supported.

Is it accessible?

The open gallery is a modal dialog with role="dialog" and aria-modal, focus moves into it on open, Tab is trapped while it is open and focus returns to the trigger on close. Slide changes are announced to screen readers, the controls are labelled and translatable, and prefers-reduced-motion disables the animations. All four packages run axe checks against WCAG 2.0 and 2.1 A and AA rules in continuous integration. The accessibility page has the full contract.

Is lightGallery free?

Yes. lightGallery is free and open source under the GPLv3, for personal and commercial projects alike, as long as the project is distributed under GPLv3-compatible terms.

How much does the commercial license cost?

A project that keeps its source proprietary needs a commercial license. It is a one-time payment, the code and every plugin are the same, and there are no feature gates.

LicensePrice (USD, one-time)Covers
Hobby48One developer, one product, not for a product that is sold
Team118Up to eight developers, up to five products, products for sale allowed
Organization188Unlimited developers and products, products for sale allowed
Extended239Unlimited developers, one product that itself produces copies, such as an SDK, site builder, theme or template

Open-source projects under a GPLv3-compatible license can request a free key. The license page has the purchase links and the full terms.

Does a version 2 license cover version 3?

No. A license covers every release within the major version it was bought for, so a 2.x license covers all 2.x releases and version 3 needs a new license. Licenses bought in the six months before the 3.0 release can be exchanged by email. Version 3 keys start with LIG; an older key keeps the gallery working and logs a console warning.
