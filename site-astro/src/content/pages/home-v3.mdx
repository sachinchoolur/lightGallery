<Fragment slot="vanilla">

```bash
npm install lightgallery
```

```js
import lightGallery from 'lightgallery';
import lgThumbnail from 'lightgallery/plugins/thumbnail';
import lgZoom from 'lightgallery/plugins/zoom';
import 'lightgallery/css/lightgallery-bundle.css';

lightGallery(document.getElementById('gallery'), {
    plugins: [lgZoom, lgThumbnail],
});
```

</Fragment>
<Fragment slot="react">

```bash
npm install @lightgallery/react
```

```tsx
import { LightGallery, LightGalleryItem } from '@lightgallery/react';
import Thumbnail from '@lightgallery/react/plugins/thumbnail';
import Zoom from '@lightgallery/react/plugins/zoom';

<LightGallery plugins={[Zoom, Thumbnail]}>
    {items.map((item) => (
        <LightGalleryItem key={item.src} item={item}>
            <img src={item.thumb} alt={item.alt} />
        </LightGalleryItem>
    ))}
</LightGallery>;
```

</Fragment>
<Fragment slot="vue">

```bash
npm install @lightgallery/vue
```

```vue
<script setup>
import { LightGallery, LgItem } from '@lightgallery/vue';
import Thumbnail from '@lightgallery/vue/plugins/thumbnail';
import Zoom from '@lightgallery/vue/plugins/zoom';
</script>

<template>
    <LightGallery :plugins="[Zoom, Thumbnail]">
        <LgItem v-for="item of items" :key="item.src" :item="item">
            <img :src="item.thumb" :alt="item.alt" />
        </LgItem>
    </LightGallery>
</template>
```

</Fragment>

```bash
npm install @lightgallery/angular

<lg-gallery [features]="[withZoom(), withThumbnail()]">

        </a>
    }
</lg-gallery>
```

            <h2>Phones first</h2>
            <p>Most gallery views happen on a phone, so the defaults assume one.</p>
            <ul class="home-checklist">
                <li><strong>Separate mobile settings.</strong> A second settings object applies on small screens, so the toolbar can be lean where space is tight.</li>
                <li><strong>CSS does the sizing.</strong> Images and videos fit by stylesheet rules, not per-slide measurement, so rotation and resize cost nothing.</li>
                <li><strong>Phone-sized files.</strong> Responsive image ladders and <code>srcset</code> mean a phone never downloads the desktop original.</li>
                <li><strong>Video on a budget.</strong> Facades keep cellular data for the videos people actually press play on.</li>
                <li><strong>The native share sheet</strong> where the browser has one, social links where it doesn't.</li>
            </ul>
