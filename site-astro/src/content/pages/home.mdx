<Fragment slot="vanilla">

<p class="home-stack-desc">Plain JavaScript and TypeScript, with no dependencies. Point it at your markup or an array of items, from npm or a CDN tag.</p>

```bash
npm install lightgallery
```

```js
import lightGallery from 'lightgallery';
import lgThumbnail from 'lightgallery/plugins/thumbnail';
import lgZoom from 'lightgallery/plugins/zoom';
import 'lightgallery/css/lightgallery-bundle.css';

lightGallery(document.getElementById('gallery'), {
    plugins: [lgZoom, lgThumbnail],
});
```

</Fragment>
<Fragment slot="react">

<p class="home-stack-desc">A real React component: props, children, refs and callbacks. Your state stays in React, and everything is typed.</p>

```bash
npm install @lightgallery/react
```

```tsx
import { LightGallery, LightGalleryItem } from '@lightgallery/react';
import Thumbnail from '@lightgallery/react/plugins/thumbnail';
import Zoom from '@lightgallery/react/plugins/zoom';

<LightGallery plugins={[Zoom, Thumbnail]}>
    {items.map((item) => (
        <LightGalleryItem key={item.src} item={item}>
            <img src={item.thumb} alt={item.alt} />
        </LightGalleryItem>
    ))}
</LightGallery>;
```

</Fragment>
<Fragment slot="vue">

<p class="home-stack-desc"><code>v-model</code> for the open state, slots for captions and controls, <code>Teleport</code> for the overlay.</p>

```bash
npm install @lightgallery/vue
```

```vue
<script setup>
import { LightGallery, LgItem } from '@lightgallery/vue';
import Thumbnail from '@lightgallery/vue/plugins/thumbnail';
import Zoom from '@lightgallery/vue/plugins/zoom';
</script>

<template>
    <LightGallery :plugins="[Zoom, Thumbnail]">
        <LgItem v-for="item of items" :key="item.src" :item="item">
            <img :src="item.thumb" :alt="item.alt" />
        </LgItem>
    </LightGallery>
</template>
```

</Fragment>
<Fragment slot="angular">

<p class="home-stack-desc">Standalone components, signals, zoneless change detection and a CDK overlay, nothing bolted on.</p>

```bash
npm install @lightgallery/angular
```

```html
<lg-gallery [features]="[withZoom(), withThumbnail()]">
    @for (item of items; track item.src) {
        <a [lgGalleryItem]="item">
            <img [src]="item.thumb" [alt]="item.alt" />
        </a>
    }
</lg-gallery>
```

</Fragment>

            <details class="home-faq-item"><summary>Is it free?</summary><p>lightGallery is open source under the GPLv3. If your project can't be distributed under the GPL, a <a href="/license/">commercial license</a> covers it, same code, no feature gates.</p></details>
            <details class="home-faq-item"><summary>Does it need jQuery?</summary><p>No. lightGallery has no dependencies. The only jQuery on this site is for the two demos that integrate third-party jQuery carousels.</p></details>
            <details class="home-faq-item"><summary>Which frameworks are supported?</summary><p>Plain JavaScript and TypeScript, plus native packages for React, Vue and Angular, the same features in all of them. For anything else, the gallery's core is available on its own as <code>@lightgallery/headless</code>.</p></details>
            <details class="home-faq-item"><summary>Which browsers?</summary><p>Current evergreen browsers and iOS Safari. There are no polyfills and no legacy builds.</p></details>
            <details class="home-faq-item"><summary>I'm on version 2. What changes?</summary><p>The vanilla API is unchanged. The framework wrappers are replaced by native packages and the icon font is gone. The <a href="/docs/migration/">migration guide</a> lists every step.</p></details>
            <details class="home-faq-item"><summary>Are TypeScript types included?</summary><p>Yes, every package ships its own types; settings, events and plugin options are fully typed.</p></details>
