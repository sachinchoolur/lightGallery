Let's see how we can change the background color of the gallery on every slide
change.

##### Setup

<CodeTabs>
<Fragment slot="vanilla">

**HTML**

```html
<div id="custom-events-demo">
    <a href="img/img1.jpg">
        <img src="img/thumb1.jpg" />
    </a>
    <a href="img/img2.jpg">
        <img src="img/thumb2.jpg" />
    </a>
    <!-- more items -->
</div>
```

**JavaScript**

```js
const colours = ['#6a7583', '#1e304b', '#315460', '#080607'];
const galleryEventsDemo = document.getElementById('custom-events-demo');
galleryEventsDemo.addEventListener('lgBeforeSlide', (event) => {
    const { index } = event.detail;
    document.querySelector('.lg-backdrop').style.backgroundColor =
        colours[index];
});
lightGallery(galleryEventsDemo, {
    addClass: 'lg-events-demo-outer', // (Optional)
});
```

</Fragment>
<Fragment slot="react">

```tsx
// Every lg* event is a typed callback prop.
<LightGallery
    slides={slides}
    className="lg-events-demo-outer"
    onBeforeSlide={({ index }) => setBackdrop(colours[index])}
/>
```

</Fragment>
<Fragment slot="vue">

```vue
<!-- Kebab-case listeners, same payloads. -->
<LightGallery
    :slides="slides"
    class-name="lg-events-demo-outer"
    @before-slide="({ index }) => setBackdrop(colours[index])"
/>
```

</Fragment>
<Fragment slot="angular">

```html
<!-- Signal outputs, same payloads. -->
<lg-gallery
    [slides]="slides"
    className="lg-events-demo-outer"
    (beforeSlide)="setBackdrop($event.index)"
/>
```

</Fragment>
