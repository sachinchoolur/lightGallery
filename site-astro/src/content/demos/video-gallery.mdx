#### External videos

<p>To display YouTube, Vimeo and Wistia, videos, you just need to paste the video URL, or share URL of the video in the data-src attribute. The same way you display images in the gallery. lightGallery will check the data-src attribute and if it is a video URL, it will create the respective video slide.</p>

<p>Provider videos render as lightweight facades by default: a poster with a play button, with the provider iframe created only when the user presses play. The poster falls back from the data-poster attribute to the YouTube thumbnail endpoint to the item thumb, so YouTube slides get a facade even without an explicit poster. Users can navigate to other slides by using mouse drag or swipe without loading any player code. See the <a href="/demos/video-facades/">video facades demo</a> for details and how to opt out.</p>

<p>lightGallery allows you to load thumbnail images automatically from YouTube and Vimeo. You can specify the size of the thumbnails in the settings. You need to use <a href="/docs/settings/#vimeo-thumbnails-plugin">Vimeo thumbnail plugin</a> to load thumbnails for vimeo videos. Videos will be automatically paused when a user starts to navigate to another slide.</p>

#### HTML5 videos

<p>For displaying HTML5 videos, you need to construct an object with array of video sources and types, and videos attributes objects as shown below and pass it via data-video attribute</p>
Note - data-src should not be provided when you use html5 videos

```tsx
import {
    LightGallery,
    LightGalleryItem,
    type GalleryItem,
} from '@lightgallery/react';
import Video from '@lightgallery/react/plugins/video';

const items: GalleryItem[] = [
    // YouTube, Vimeo and Wistia: `src` is the address of the video page.
    {
        src: '//www.youtube.com/watch?v=EIUJfXk3_3w',
        poster: 'https://img.youtube.com/vi/EIUJfXk3_3w/maxresdefault.jpg',
        thumb: 'https://img.youtube.com/vi/EIUJfXk3_3w/mqdefault.jpg',
        alt: 'Puffin Hunts Fish To Feed Puffling',
        lgSize: '1280-720',
    },
    // HTML5 video: no `src`. The same object as the vanilla data-video
    // attribute, as the item's `video` field.
    {
        video: {
            source: [{ src: '/videos/video1.mp4', type: 'video/mp4' }],
            tracks: [
                {
                    src: '/videos/title.txt',
                    kind: 'captions',
                    srclang: 'en',
                    label: 'English',
                    default: 'true',
                },
            ],
            attributes: { preload: false, controls: true },
        },
        poster: '/images/demo/html5-video-poster.jpg',
        thumb: '/images/demo/html5-video-poster.jpg',
        alt: 'Peck Pocketed',
        lgSize: '1280-720',
    },
];

// Video slides need the Video plugin.
<LightGallery plugins={[Video]}>
    {items.map((item) => (
        <LightGalleryItem key={item.poster} item={item}>
            <img src={item.thumb} alt={item.alt} />
        </LightGalleryItem>
    ))}
</LightGallery>;
```

#### Video.js example

<a href="https://videojs.com/" target="_blank">Video.js</a> is a web video
player built from the ground up for an HTML5 world. lightGallery has built-in
Video.js support: include Video.js on the page, then pass `videojs: true`
via lightGallery settings. You can also pass Video.js options via
`videojsOptions`.

Note - Make sure that you pass a proper JSON object in the data-video attribute.

custom players to your own slide markup.

#### Video Autoplay

Browsers block autoplay with sound, and whether a video may start on its
own depends on [several conditions](https://developer.chrome.com/blog/autoplay/).
To stay within the policy, lightGallery mutes the video when it autoplays the
first slide. To unmute, pass `?mute=0` (YouTube) or `?muted=false` (Vimeo) in
the video URL; lightGallery forwards query parameters to the player.

On iOS, HTML5 videos may also need `"playsinline": true` to play inside the
page rather than full screen.
