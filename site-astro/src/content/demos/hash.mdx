#### Demo

The URL syncing runs on the Navigation API where the browser supports it and
falls back to the History API everywhere else — the deep-link URL format is
identical either way. See the
<a href="/docs/hash-drivers/">hash drivers guide</a>.

<ImageGallery id="gallery-hash-demo" />

<DemoButtons react="https://stackblitz.com/edit/stackblitz-starters-fz6ajn" />

##### Setup

<CodeTabs>
<Fragment slot="vanilla">

**HTML**

```html
<div id="gallery-hash-demo">
    <a href="img/img1.jpg">
        <img src="img/thumb1.jpg" />
    </a>
    <a href="img/img2.jpg">
        <img src="img/thumb2.jpg" />
    </a>
    ...
</div>
```

**JavaScript**

```js
import lightGallery from 'lightgallery';
import lgHash from 'lightgallery/plugins/hash';

lightGallery(document.getElementById('gallery-hash-demo'), {
    plugins: [lgHash],
});

// With more than one gallery on a page, give each a unique galleryId.
/*
lightGallery(document.getElementById('gallery-hash-demo-2'), {
    plugins: [lgHash],
    galleryId: 2,
});
*/
```

</Fragment>
<Fragment slot="react">

```tsx
import { LightGallery } from '@lightgallery/react';
import Hash from '@lightgallery/react/plugins/hash';

// hashDriver 'auto' rides the Navigation API where the browser
// has it and falls back to History — see the hash drivers guide.
<LightGallery
    slides={slides}
    plugins={[Hash]}
    hash={{ galleryId: '1', hashDriver: 'auto' }}
/>;
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup>
import { LightGallery } from '@lightgallery/vue';
import Hash from '@lightgallery/vue/plugins/hash';
</script>

<template>
    <LightGallery
        :slides="slides"
        :plugins="[Hash]"
        :hash="{ galleryId: '1', hashDriver: 'auto' }"
    />
</template>
```

</Fragment>
<Fragment slot="angular">

```html
<lg-gallery
    [slides]="slides"
    [features]="[withHash({ galleryId: '1', hashDriver: 'auto' })]"
/>
```

</Fragment>
</CodeTabs>

#### Custom slide name

You can provide custom slide names for each slide by providing slide name via
`data-slide-name` attribute or `slideName` if you are using dynamic mode.

<ImageGallery id="gallery-custom-hash-demo" />

##### Setup

<CodeTabs>
<Fragment slot="vanilla">

**HTML**

```html
<div id="gallery-hash-demo">
    <a href="img/img1.jpg" data-slide-name="fading-light">
        <img src="img/thumb1.jpg" />
    </a>
    <a href="img/img2.jpg" data-slide-name="Bowness Bay">
        <img src="img/thumb2.jpg" />
    </a>
    ...
</div>
```

**JavaScript**

```js
lightGallery(document.getElementById('gallery-hash-demo'), {
    customSlideName: true,
});
```

</Fragment>
<Fragment slot="react">

```tsx
// Slide names come from each item's `slideName`, so deep links read
// /page/#lg=1&slide=fading-light instead of an index.
const slides = [
    { src: 'img/1.jpg', thumb: 'img/1-t.jpg', slideName: 'fading-light' },
];

<LightGallery
    slides={slides}
    plugins={[Hash]}
    hash={{ customSlideName: true }}
/>;
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup>
const slides = [
    { src: 'img/1.jpg', thumb: 'img/1-t.jpg', slideName: 'fading-light' },
];
</script>

<template>
    <LightGallery
        :slides="slides"
        :plugins="[Hash]"
        :hash="{ customSlideName: true }"
    />
</template>
```

</Fragment>
<Fragment slot="angular">

```html
<lg-gallery
    [slides]="slides"
    [features]="[withHash({ customSlideName: true })]"
/>
```

</Fragment>
