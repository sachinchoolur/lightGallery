Video gallery for YouTube, Vimeo and HTML5

View as Markdown Open in Claude Open in ChatGPT

lightGallery supports YouTube, Vimeo, Wistia and all other types of HTML5 video formats, such as MP4, WebM, Ogg, etc.

External videos

To display YouTube, Vimeo and Wistia videos, you just need to paste the video URL, or share URL of the video in the data-src attribute. The same way you display images in the gallery. lightGallery will check the data-src attribute and if it is a video URL, it will create the respective video slide.

Provider videos render as lightweight facades by default: a poster with a play button, with the provider iframe created only when the user presses play. The poster falls back from the data-poster attribute to the YouTube thumbnail endpoint to the item thumb, so YouTube slides get a facade even without an explicit poster. Users can navigate to other slides by using mouse drag or swipe without loading any player code. See the video facades demo for details and how to opt out.

lightGallery allows you to load thumbnail images automatically from YouTube and Vimeo. You can specify the size of the thumbnails in the settings. You need to use Vimeo thumbnail plugin to load thumbnails for vimeo videos. Videos will be automatically paused when a user starts to navigate to another slide.

HTML5 videos

For displaying HTML5 videos, you need to construct an object with array of video sources and types, and videos attributes objects as shown below and pass it via data-video attribute

Note - data-src should not be provided when you use HTML5 videos.

Video.js example

Video.js is a web video player built from the ground up for an HTML5 world. lightGallery has built-in Video.js support: include Video.js on the page, then pass videojs: true via lightGallery settings. You can also pass Video.js options via videojsOptions.

Note - Make sure that you pass a proper JSON object in the data-video attribute.

/>

JavaScript

lightGallery(document.getElementById('gallery-videojs-demo'), {
    plugins: [lgVideo],
    videojs: true,
    videojsOptions: {
        muted: true,
    },
});

The videojs bridge is vanilla-only. The React, Vue and Angular packages render HTML5 video with the native <video> element and leave custom players to your own slide markup.

Video Autoplay

Browsers block autoplay with sound, and whether a video may start on its own depends on several conditions. To stay within the policy, lightGallery mutes the video when it autoplays the first slide. To unmute, pass ?mute=0 (YouTube) or ?muted=false (Vimeo) in the video URL; lightGallery forwards query parameters to the player.

On iOS, HTML5 videos may also need "playsinline": true to play inside the page rather than full screen.
